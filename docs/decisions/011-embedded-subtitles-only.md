# 011 — Embedded audio and subtitle tracks only

**Date:** October 2026 (the TV app) · **Status:** accepted · **Rules:** TRACKS-1

## Decision

The players offer the tracks inside the media file; no subtitles fetched from the server or
elsewhere.

## Ruled out

- **Subtitles from the server or elsewhere**: a standing rule since the TV app ("don't add
  server-side subtitles", CLAUDE.md); no reason was recorded with it.
